Before the catalogue.

THEMIS (Θέμις) is AIMarket’s publish-time admission gate: a signed approve / review / reject from a bounded dossier. Not Metis (cognition). Not WARDEN (invoke-time firewall).

Run the agent Rebuild from the mini-course 
uvx create-aimarket-agent themis --kind tool --metis

Deterministic first

Policy engine decides immediately. Metis may advise asynchronously — it never overrides the signed verdict.

Evidence, not SSRF

Candidate URLs and evidence links are parsed, never fetched. Unknown fields and oversized bodies fail closed.

Hub overlay

Optional Hub modes off / advisory / enforce. Listing already needs token, stake, signatures — not open signup.

Mini-course: build this agent

THEMIS is the finished reference repository for the five-language create-aimarket-agent tutorial. Twelve steps: scaffold → dossier → findings → lazy Metis → Ed25519 → tests → Docker → deliberate publish.
